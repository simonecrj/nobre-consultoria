# Nobre Consultoria — Método ReStart (Camila Nobre) v2

Landing page responsiva e acessível (WCAG) desenvolvida em **React + Vite + Tailwind CSS** com identidade visual fiel à paleta da marca, fotografia oficial da mentora, QR Code do Instagram, barra flutuante de acessibilidade e carrinho de compras integrado ao WhatsApp.

## Como rodar o projeto localmente

1. Instale o **Node.js** (versão 18 ou superior).
2. Extraia o arquivo `.zip` e abra o terminal na pasta `nobre-consultoria-restart`.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Rode o projeto:
   ```bash
   npm run dev
   ```
